Lions Cricket Academy Manager — Client Demo
=============================================
Open index.html in Chrome/Edge/Safari.

This is a functional UI prototype for client presentation:
- Premium 3D/neo-glass navy + gold design
- Dashboard, Students, Admissions, Fees & Payments, Attendance
- Tournaments, Matches, Player Performance, Training, Reports
- Communications and Settings
- Working forms with localStorage persistence
- Payment dropdowns and save/validation
- Responsive mobile/tablet/desktop layout
